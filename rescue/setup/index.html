Setup / recovery mode
  1. Insert a USB 3.0 stick with rootfs.tar.xz (FAT32 or ext4) — the installer finds it automatically.
  2. Plug in one or two SATA disks for your data.
  3. Review the detected devices, then dry-run before installing.
Nothing is written until you type ERASE and press Install. If you already have a bootable Debian USB stick, remove it, re-insert and reboot — this page only appears when no OS is found.
